REST API Documentation

GET /api/health

Returns application health status, dataset load stats, and model training diagnostics.

// Response
{
  "status": "healthy",
  "dataset_loaded": true,
  "records_count": 10000,
  "ml_trained": true,
  "features_count": 400
}
POST /api/analyze

Evaluates hybrid sentiment metrics and extracted word signals for a single input text.

// Request Body
{
  "text": "SentiPulse is an awesome platform! The results are fantastic."
}

// Response
{
  "consensus_label": "Positive",
  "text": "SentiPulse is an awesome platform! The results are fantastic.",
  "vader": {
    "compound": 0.8398,
    "label": "Positive",
    "neg": 0.0,
    "neu": 0.467,
    "pos": 0.533
  },
  "ml": {
    "confidence": 0.543,
    "label": "Neutral",
    "matched_features": ["awesome", "fantastic"]
  },
  "processing_time_ms": 1.35
}
POST /api/batch

Bulk sentiment evaluation for an array of text strings (max 50 per request).

// Request Body
{
  "texts": [
    "Great product!",
    "Terrible service and server crashes."
  ]
}
